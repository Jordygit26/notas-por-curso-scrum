# 📘 Notas por Curso – Scrum + JavaScript Vanilla 

Hemos desarollado un proyecto colaborativo aplicando **Scrum**, **GitHub** y **JavaScript Vanilla**, cuyo objetivo es crear una aplicación web funcional que permita registrar notas por curso, calcular promedios y persistir la información en el navegador.

---

## 🎯 Objetivo del Proyecto

Aplicar la metodología **Scrum** y el trabajo colaborativo con **GitHub** para desarrollar una aplicación web funcional utilizando **JavaScript Vanilla**, evidenciando el aprendizaje técnico y organizacional del equipo.

---

## ⏱️ Duración del Sprint

El proyecto se desarrolló en un **Sprint de 3 días**:

- **Día 1:**  
  Sprint Planning y comienzo del desarrollo (creación del repositorio).

- **Día 2:**  
  Daily Scrum y desarrollo de la estructura HTML, estilos CSS y funcionalidades JavaScript (DOM, validaciones, localStorage, renderizado).

- **Día 3:**  
  Daily Scrum, integración final del código, resolución de conflictos al momento de hacer PR, Sprint Review y Sprint Retrospective.
  
---

## 🧠 Metodología Scrum Aplicada

### Eventos Scrum
- Sprint Planning  
- Daily Scrum (mínimo 2 durante el Sprint)  
- Sprint Review  
- Sprint Retrospective  

### Artefactos Scrum
- **Sprint Goal:**  
  Desarrollar una aplicación web funcional en JavaScript Vanilla que permita registrar notas por curso, calcular el promedio y persistir los datos utilizando localStorage.

- **Sprint Backlog:**  
  Gestionado mediante un tablero **Trello**, con tareas organizadas en columnas *To Do*, *In Progress* y *Done*.

- **Incremento:**  
  Aplicación web completamente funcional.

---

## 🧰 Tecnologías Utilizadas

- HTML5

- JavaScript Vanilla  

### Uso obligatorio aplicado:
- Manipulación del DOM  
- Manejo de eventos

---

## 🌐 Funcionalidades del Proyecto

- Registro de notas por curso mediante formulario  
- Listado dinámico de notas en tabla  
- Cálculo automático del promedio  
- Validaciones de datos (nota entre 0 y 20)  
- Mensajes de error y éxito  
- Persistencia de datos usando `localStorage`  
- Eliminación de notas individuales  

---

## 🗂️ Flujo de Trabajo en GitHub

- Repositorio único por equipo  
- Uso de ramas:
  - `main`
  - `dev`
  - `feature/*`
- No se trabajó directamente sobre `main` a 
- Uso de múltiples Pull Requests  
- Cada Pull Request fue revisado por otro integrante  
- Commits con mensajes claros y descriptivos  

---

## ▶️ Cómo Ejecutar el Proyecto

1. Clonar o descargar el repositorio.
2. Abrir el archivo `index.html` en cualquier navegador web moderno.
3. No es necesario instalar dependencias ni herramientas adicionales, el `index.html` funciona gracias a que el js y css se encuentran en el mismo directorio.
